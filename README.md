# RNA-Seq Based Differential Gene Expression Analysis

## Project Overview

This project focuses on identifying differentially expressed genes from RNA-Seq datasets and performing functional enrichment analysis to understand biological pathways.

## Objectives

- Perform RNA-Seq data analysis
- Identify significant differentially expressed genes
- Visualize gene expression patterns
- Perform pathway enrichment analysis

## Tools and Technologies

- R Programming
- Bioconductor
- DESeq2
- ggplot2
- clusterProfiler
- Linux environment

## Workflow

Raw RNA-Seq Data  
↓  
Quality Control  
↓  
Differential Expression Analysis  
↓  
Functional Annotation  
↓  
Pathway Enrichment Analysis
